# Outlook 邮件模板工具（Excel VBA 版）

## 1. 方案与运行条件

本工具完全在 Excel 中运行，通过 VBA 调用经典版 Outlook 自带的 COM 接口。它使用当前 Windows 用户已经登录的 Outlook 配置，不需要在工具中再次登录 Microsoft 365，也不依赖 Java、PowerShell、Access、Windows 任务计划程序、第三方 DLL 或自定义 EXE。

支持两种使用方式：

- 手动生成：默认打开一封可编辑邮件；也可勾选“确认后自动发送”，每次点击仍先显示确认框。
- 循环发送：按模板每天或每周直接发送。启用任务时只确认一次，之后到达计划时间不再弹窗。

循环任务由 Excel `Application.OnTime` 驱动，因此 Excel 必须一直打开，Windows 用户必须保持登录，电脑不能休眠。Excel 必须在计划秒及时执行回调；只要执行时已经晚于计划时间，本次就记录为“已错过”，不补发、不重试，并计算下一次发送时间。

## 2. 首次安装

由于交付环境不能替你生成或签署公司的宏文件，首次需要在 Windows Excel 中导入一次 VBA 模块：

1. 打开 `Outlook邮件模板工具.xlsx`。
2. 选择“文件 → 另存为”，文件类型选择“Excel 启用宏的工作簿 (*.xlsm)”。
3. 按 `Alt+F11` 打开 VBA 编辑器。
4. 在 VBA 编辑器中选择“文件 → 导入文件”，导入 `vba\modOutlookTemplateTool.bas`。
5. 保存工作簿，回到 Excel。
6. 按 `Alt+F8`，选择并运行 `SetupWorkbook`。
7. 再次保存工作簿。以后直接打开这个 `.xlsm` 文件即可。

`SetupWorkbook` 会在“邮件工具”创建载入、预览、生成邮件按钮、自动发送复选框和参数滚动条，也会在“定时任务”创建任务按钮。如果重复运行，它会先替换旧控件，不会重复叠加。

如果公司阻止未签名宏，请让 IT 把工作簿放入批准的受信任位置，或者使用公司证书签署 VBA 项目。工具不会绕过公司的宏安全策略。

## 3. 编辑模板

在“模板库”工作表中直接编辑模板。每行是一套模板，包含模板名称、收件人、抄送、主题和正文。模板名称必须唯一，抄送可以留空。

收件人和抄送支持 Outlook 常用格式：

```text
Jim zheng<jim_zheng@mail.com>
Jim zheng <jim_zheng@mail.com>
jim_zheng@mail.com
```

多人使用英文或中文分号分隔：

```text
Jim zheng<jim_zheng@mail.com>; Jane Lee<jane_lee@mail.com>
```

## 4. 模板参数与滚动区

参数写成 `{{参数名}}`，可以出现在收件人、抄送、主题和正文中。例如：

```text
{{收件人姓名}}<{{收件人邮箱}}>
付款提醒 - {{姓名}} - {{batch_date}}
```

选择模板并点击“载入模板”后，只显示该模板实际用到的参数。同名参数只显示一次。参数区固定显示 6 行；参数较多时使用第 18 行的滚动条。黄色单元格需要手动填写，灰色单元格由日期函数计算。

支持的日期参数：

| 写法 | 结果 |
|---|---|
| `{{batch_date}}` | 基准日期减 1 天，默认 `yyyy-mm-dd` |
| `{{batch_date:yyyy年m月d日}}` | 基准日期减 1 天，并使用指定格式 |
| `{{今天}}` 或 `{{today}}` | 基准日期 |
| `{{今天+7天:yyyy-mm-dd}}` | 基准日期加 7 天 |
| `{{今天-1天:yyyy-mm-dd}}` | 基准日期减 1 天 |

手动生成时，基准日期是当天；定时发送时，基准日期是该次计划发送日期。因此任务错过后不会用实际打开 Excel 的日期补算旧邮件。所有参数，包括 `batch_date`，都只有在当前模板使用时才显示。

## 5. 手动打开或发送一封邮件

1. 在“邮件工具”选择模板并点击“载入模板”。
2. 填写黄色参数，使用滚动条检查全部参数。
3. 点击“更新预览”，检查收件人、抄送、主题和正文。
4. 不勾选“确认后自动发送”时，点击“生成邮件”会打开 Outlook 可编辑邮件窗口。
5. 勾选后，点击“生成邮件”会先显示确认框；选择“是”才直接发送。

每次只处理一封邮件。失败后不会自动重试。如果 Outlook 返回不确定结果，请先检查“已发送邮件”。Outlook 或公司的安全策略可能继续显示程序访问提示，工具不会自动关闭这些提示。

## 6. 新建每天或每周任务

“定时任务”第 6 行开始每行一个任务。黄色列由用户填写：

| 列 | 填写内容 |
|---|---|
| 任务名称 | 自定义名称 |
| 启用 | 可先留空或选择 NO，保存确认后自动改为 YES |
| 模板 | 从模板库选择 |
| 频率 | `1` 表示每天，`2` 表示每周 |
| 星期 | 每周任务填 `1` 至 `7`，分别代表周一至周日；每天任务可留空 |
| 发送时间 | Excel 时间，例如 `09:00:00` |

建立任务步骤：

1. 在“定时任务”填写任务名称、模板、频率、星期和发送时间，并选中该行。
2. 点击“加载选中任务”。Excel 会切到“邮件工具”并载入该模板。
3. 填写所有黄色参数。日期参数会在每次计划发生时重新计算。
4. 回到“定时任务”，选中同一行，点击“保存并启用”。
5. 检查确认框中的任务、收件人、抄送、主题和时间，选择“是”。

启用后，“下一次发送”会自动计算。固定参数保存在“参数快照”中；日期函数不会保存结果，而会在每次计划发生时重新计算。

## 7. 管理和测试任务

- **加载选中任务**：把所选任务的模板和固定参数载入“邮件工具”，用于修改。
- **保存并启用**：重新确认并启用任务，同时重新计算下一次发送时间。
- **暂停任务**：把任务设为 NO，清除下一次发送时间。
- **刷新计划**：检查所有启用任务、处理已经错过的时间，并注册最近一次回调。
- **测试并打开邮件**：按任务参数创建一封可编辑邮件，不直接发送，也不改变任务的发生记录。

模板内容或参数结构发生变化后，相关任务会自动暂停并显示“模板已变化，等待重新确认”。请重新加载任务、检查参数并保存启用。这样可以防止旧参数快照套用到已经修改的模板。

## 8. 错过、失败与重复保护

- 计划时间已经过去：状态记为“已错过”，不会补发，下一次时间按每天或每周规则计算。
- Excel 忙碌、关闭、用户退出或电脑休眠：恢复时同样按“已错过”处理。
- 发送前失败：状态记为“发送失败”，不自动重试。
- 调用 Outlook 发送后出现错误：状态记为“结果不确定”，不自动重试；请先查“已发送邮件”。
- 每个计划发生时间会保存唯一发生键，避免同一周期重复发送。

工作簿会在任务状态变化时保存，因此运行循环任务的 `.xlsm` 文件必须可写，不能以只读方式打开。

## 9. 兼容性与限制

- 支持：Windows 桌面版 Excel、经典版 Outlook、当前 Windows 用户的 Outlook 配置。
- 不支持：新版 Outlook 的直接创建和发送，因为新版 Outlook 不提供 VBA 使用的传统 COM 接口。
- 当前不包含附件、富文本、内嵌图片或外部数据取值。
- 任务仅支持每天和每周循环，每次一封。
- 计划依赖 Excel 常驻，不是后台 Windows 服务。

建议首次测试时把自己的邮箱作为收件人，先使用“测试并打开邮件”，确认内容和地址都能由 Outlook 正确解析，再启用循环任务。

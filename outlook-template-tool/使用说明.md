# Outlook 邮件模板工具（Excel VBA 版）

## 1. 方案说明

本工具完全在 Excel 中运行，通过 VBA 调用经典版 Outlook 自带的 COM 接口。它使用当前 Windows 用户已经登录的 Outlook 配置，不需要在工具中再次登录 Microsoft 365。

工具不依赖 Java、PowerShell、Access、第三方 DLL 或自定义 EXE。

## 2. 首次安装

由于当前交付环境不能替你生成或签署公司的宏文件，首次需要在 Windows Excel 中导入一次 VBA 模块：

1. 打开 `Outlook邮件模板工具.xlsx`。
2. 选择“文件 → 另存为”，文件类型选择“Excel 启用宏的工作簿 (*.xlsm)”。
3. 按 `Alt+F11` 打开 VBA 编辑器。
4. 在 VBA 编辑器中选择“文件 → 导入文件”，导入 `vba\modOutlookTemplateTool.bas`。
5. 保存工作簿，回到 Excel。
6. 按 `Alt+F8`，选择并运行 `SetupWorkbook`。该操作会创建“载入模板”“更新预览”“生成邮件”三个按钮和“确认后自动发送”复选框。
7. 再次保存工作簿。以后直接打开这个 `.xlsm` 文件即可。

如果公司阻止未签名宏，请让 IT 把工作簿放入批准的受信任位置，或者使用公司证书签署 VBA 项目。工具不会绕过公司的宏安全策略。

## 3. 编辑模板

在“模板库”工作表中直接编辑模板。每行是一套模板，包含：

- 模板名称
- 收件人
- 抄送
- 主题
- 正文

模板名称必须唯一。抄送可以留空。

收件人和抄送人支持 Outlook 常用格式：

```text
Jim zheng<jim_zheng@mail.com>
Jim zheng <jim_zheng@mail.com>
jim_zheng@mail.com
```

多人使用英文或中文分号分隔：

```text
Jim zheng<jim_zheng@mail.com>; Jane Lee<jane_lee@mail.com>
```

## 4. 模板变量

手动变量写成 `{{变量名}}`，可以放在收件人、抄送、主题和正文中。例如：

```text
{{收件人姓名}}<{{收件人邮箱}}>
付款提醒 - {{姓名}} - {{batch_date}}
```

在“邮件工具”工作表选择模板并点击“载入模板”，工具会列出该模板中的手动变量。黄色单元格用于填写内容。同名变量只需填写一次。

支持以下日期变量：

| 写法 | 结果 |
|---|---|
| `{{batch_date}}` | 当前日期减 1 天，默认 `yyyy-mm-dd` |
| `{{batch_date:yyyy年m月d日}}` | 当前日期减 1 天，并使用指定格式 |
| `{{今天}}` 或 `{{today}}` | 当前日期 |
| `{{今天+7天:yyyy-mm-dd}}` | 当前日期加 7 天 |
| `{{今天-1天:yyyy-mm-dd}}` | 当前日期减 1 天 |

`batch_date` 是可选变量：模板未使用时不会影响邮件；模板使用时由 VBA 在生成邮件的当天自动计算，不能用手动输入覆盖。

## 5. 打开可编辑邮件

1. 在“邮件工具”选择模板。
2. 点击“载入模板”，填写黄色变量单元格。
3. 点击“更新预览”并检查收件人、抄送、主题和正文。
4. 保持“确认后自动发送”未勾选。
5. 点击“生成邮件”。

工具会使用经典版 Outlook 当前账号创建并打开一封可编辑邮件。你可以在 Outlook 中继续修改并手动发送。

## 6. 确认后自动发送

1. 勾选“确认后自动发送”。
2. 点击“生成邮件”。
3. 工具显示收件人、抄送、主题和正文预览。
4. 选择“是”后才会调用 Outlook 发送；选择“否”或关闭窗口不会发送。

为避免重复发送，工具不会在失败后自动重试。若 Outlook 返回不确定结果，请先检查“已发送邮件”。Outlook 或公司的安全策略可能继续显示程序访问提示，工具不会自动关闭这些提示。

## 7. 兼容性

- 支持：Windows 桌面版 Excel、经典版 Outlook、当前 Windows 用户的 Outlook 配置。
- 不支持：新版 Outlook 的直接创建和发送，因为新版 Outlook 不提供 VBA 使用的传统 COM 接口。
- 每次仅生成或发送一封邮件。
- 当前不包含附件、富文本或内嵌图片。

建议首次测试时把自己的邮箱作为收件人，先测试“打开可编辑邮件”，确认无误后再测试自动发送。
